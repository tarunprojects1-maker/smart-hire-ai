# SmartHire AI

SmartHire AI is an AI-powered ATS Resume Analyzer and Career Intelligence Platform designed to help students, freshers, and job seekers improve their resumes, increase ATS compatibility, and align their profiles with real job descriptions.

The platform analyzes resumes and job descriptions, identifies missing skills, evaluates ATS performance, provides recruiter-focused feedback, detects suspicious job postings, and generates ATS-optimized resumes using AI.

# How SmartHire AI Works

### Step 1: Upload Resume

Upload a resume in PDF format.

### Step 2: Add Job Description

Paste or upload the target Job Description.

### Step 3: ATS Analysis

SmartHire AI analyzes:

* Resume content
* Skills
* Keywords
* ATS compatibility
* Recruiter visibility

### Step 4: Resume vs JD Comparison

The system compares:

* Resume Skills
* JD Skills
* Matched Skills
* Missing Skills

### Step 5: AI Resume Rebuild

The AI reconstructs the resume using:

* Existing resume information
* Job description requirements
* ATS optimization principles

### Step 6: Download Optimized Resume

Users can preview and download their ATS-optimized resume.
